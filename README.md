# Sector Report downloads

Installers for **CCG Sector Report**, the pace analysis tool for Al Kamel timing data by
[Competition Controls Group](https://competitioncontrols.com/sector-report/).

## Download

**[Download the latest version](https://github.com/CmpCtrl/sector-report/releases/latest/download/CCG_SectorReport_Setup.exe)**
(Windows 10/11, 64-bit), or pick a version on the [Releases](https://github.com/CmpCtrl/sector-report/releases) page.
Each release lists what changed.

Run the installer; no administrator rights are needed. To update, run the new installer over the old one; your
setups and report styles are kept.

The installer is signed by Competition Controls Group, LLC. If Windows SmartScreen shows a warning for a new release,
choose *More info* > *Run anyway* after checking the publisher name.
